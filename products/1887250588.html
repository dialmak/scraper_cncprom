Кронштейн модульний для акумуляторів 18650 (подвійний)

Тримач для акумуляторів типу 18650, виготовлений із міцного та вогнестійкого ABS-пластику. Конструкція має пази для з'єднання кількох тримачів між собою, що дозволяє формувати міцні конструкції для складання акумуляторних батарей.

Модель розрахована на встановлення двох акумуляторів 18650. Отвори для акумуляторів мають діаметр 18,5 мм.

Тримач підходить для самостійного складання акумуляторних батарей та інших конструкцій на основі елементів 18650. 

Зверніть увагу! Для повноцінного встановлення акумуляторів необхідно використовувати верхню та нижню частини тримача.

Особливості:

  • міцна конструкція з'єднання між отворами;
  • стійкість до механічних впливів;
  • стійкість до нагрівання акумуляторів;
  • виготовлення з вогнестійкого ABS-пластику;
  • можливість з'єднання кількох тримачів між собою.

Характеристики:

  • Матеріал: ABS-пластик;
  • Кількість посадкових місць: 2;
  • Відстань між отворами: 20 мм;
  • Діаметр отвору: 18,5 мм;
  • Зовнішні розміри: 42×21,7×8,5 мм;
  • Тип акумулятора: 18650;
  • Можливість з'єднання кількох тримачів: є.
