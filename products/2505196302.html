Пристрій ручного керування для верстатів із ЧПК (CNC) використовується для переміщення інструменту або робочого столу по координатних осях у ручному режимі. Дає можливість виконувати налаштування нуля, тестування, ручне позиціонування та допоміжні операції при роботі з ЧПК. Налаштування нуля, тестування, ручне позиціонування, допоміжні операції при роботі з ЧПК.

Ручний пульт керування дозволяє оператору швидко та зручно переміщати шпиндель або стіл верстата по осях X+, Y+, Z+, A+, X-, Y-, Z-, A- у потрібному напрямку. Завдяки компактним розмірам та простому підключенню він значно полегшує налаштування та обслуговування обладнання. Підключається безпосередньо до плати керування через послідовний порт DB9, що забезпечує стабільний і надійний зв’язок із системою.
Цей пульт є зручним інструментом для операторів ЧПУ, оскільки дозволяє виконувати ручне керування безпосередньо біля робочої зони, не використовуючи програмне забезпечення.

Технічні характеристики:

Тип пристрою: ручний пульт керування (Manual control box)

Керовані осі: X+, Y+, Z+, A+,X-, Y-, Z-, A-

Функції: переміщення в позитивному (+) та негативному (–) напрямках по кожній осі

Живлення: послідовний порт DB9

Матеріал корпусу: пластик

Довжина кабелю: 136 мм

Габаритні розміри: 102х53х17 мм

Вага: 95 г
