MK-B5A16V2C — активний балансир (еквалайзер) для 2 акумуляторів, 5A


MK-B5A16V2C — це активний балансир напруги, призначений для вирівнювання заряду між двома акумуляторами у послідовному або паралельному з’єднанні. Пристрій перерозподіляє енергію від більш зарядженої батареї до менш зарядженої батареї, забезпечуючи стабільну роботу системи та подовжуючи ресурс акумуляторів. Балансування відбувається автоматично та пропорційно різниці напруг. Балансир дозволяє підключати кілька модулів паралельно, що розширює можливості використання для великих акумуляторних систем.

Модель підтримує свинцево-кислотні , літій-іонні та літій-залізо-фосфатні акумулятори. Завдяки струму активного балансування до 5А пристрій ефективно працює у складі автономних, резервних та інверторних систем живлення.

Балансир оснащений LCD-дисплеєм для відображення напруги Bat.1 та Bat.2, рівня заряду, а також обраного режиму батареї. Монтаж здійснюється на DIN-рейку, що спрощує встановлення у щитових або розподільчих шафах.

Особливості:

  • Активне балансування з перерозподілом енергії
  • Струм балансування: до 5A
  • Підтримка 2 батарей на один модуль
  • Підтримка паралельного підключення кількох модулів (каскадування через P1/P2)
  • LCD-дисплей + LED-індикація
  • 5 режимів для різних типів акумуляторів (B01–B05)
  • Автоматичне збереження налаштувань
  • Монтаж на DIN-рейку
  • Подовжувальні кабелі 1 м

Підтримувані типи акумуляторів:
Свинцево-кислотні (LAB):

  • 2 В / 6 В / 12 В

Li-ion (1–4S):

  • 3.7 В / 7.4 В / 11.1 В / 14.8 В

LiFePO4 (1–4S):

  • 3.2 В / 6.4 В / 12.8 В

Діапазон напруги однієї батареї: 7–18 В
Робоча напруга модуля: 16 В

Підключення:

  • B1+ / B1− — перша батарея (Bat-1)
  • B2+ / B2− — друга батарея (Bat-2)
  • P1 / P2 − — паралельне з’єднання декількох балансирів

Один модуль працює з двома акумуляторами. Для систем 48V, 72V, 96V, 110V, 220V, 240V використовуються кілька модулів, з’єднаних паралельно.

Налаштування:

  1. Підключити Bat-1 (B1+ / B1−).
  2. Натиснути та утримувати кнопку SET 5 секунд — почне блимати режим.
  3. Кнопками SET або DOWN вибрати потрібний тип батареї (B01–B05).
  4. Через 5 секунд без натискання налаштування зберігаються автоматично.
  5. Після цього підключити Bat-2.
  6. Балансувальний струм не залежить від обраного режиму.

Важливо.
Дві батареї повинні бути одного типу.

Бажано використовувати акумулятори однакової ємності та ступеня зношення.

Один модуль працює лише з двома батареями.

Після підключення кількох модулів повне вирівнювання напруги може тривати кілька годин.
