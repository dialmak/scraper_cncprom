Автономний контролер DDCS V4.1, 3 осі управління для ЧПК верстатів

DDCS V4.1 — це автономний контролер для систем числового програмного керування (ЧПК), призначений для керування трьохосьовими фрезерними, гравірувальними та деревообробними верстатами. Контролер працює без постійного підключення до комп’ютера та підтримує виконання G-code програм напряму з USB-накопичувача або через Ethernet-підключення. Система побудована на базі ARM9 процесора та FPGA-алгоритмів, де ARM відповідає за інтерфейс користувача та аналіз G-коду, а FPGA забезпечує генерацію високоточних імпульсів керування приводами. Така архітектура дозволяє отримати стабільну роботу, точне позиціонування осей та плавний рух навіть при виконанні складних траєкторій із великою кількістю коротких сегментів.

Контролер підтримує роботу з кроковими двигунами та сервоприводами через сигнали STEP/DIR у Differential Mode або Double Pulse Mode. Максимальна частота імпульсного сигналу становить до 500 кГц на кожну вісь, що дозволяє використовувати DDCS V4.1 у високошвидкісних системах ЧПК. Підтримується лінійна інтерполяція по 2–3 осях та кругова інтерполяція по двох осях. Контролер сумісний зі стандартним Fanuc G-code та підтримує роботу з популярними CAD/CAM програмами, включаючи ArtCam, MasterCam, Fusion 360, Aspire, JDSoft SurfMill та іншими системами підготовки керуючих програм.

Контролер оснащений 7-дюймовим TFT-дисплеєм із роздільною здатністю 1024×600 та 18 функціональними клавішами для керування верстатом без використання зовнішнього ПК. Контролер підтримує функції ручного переміщення осей (Jog), роботу з MPG-пультом, вимірювання довжини інструмента, роботу з датчиками, симуляцію траєкторії, запуск програми з конкретного рядка та відновлення роботи після аварійного вимкнення або втрати живлення. Для підключення периферії та драйверів у комплекті передбачена плата комутації PORT FOR DDCSV3.1/V4.1 з клемними колодками та DB37 інтерфейсом. Плата забезпечує зручне підключення драйверів осей, кінцевих датчиків, шпинделя, аварійної зупинки та цифрових входів/виходів.

Контролер підтримує два режими керування шпинделем: аналоговий вихід 0–10V для роботи з частотними перетворювачами VFD та режим Servo Spindle через імпульсне керування. DDCS V4.1 підтримує функції Pause Breakpoint, Power-Cut Recovery Breakpoint та Loaded Breakpoint, що дозволяє продовжити обробку після зупинки або вимкнення живлення. Для підвищення безпеки реалізовано налаштування плавного гальмування при аварійній зупинці ESTOP, що допомагає уникнути втрати позиції та механічних пошкоджень верстата.
