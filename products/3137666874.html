Пластикова нитка (філамент) для 3D-принтера Bambu Lab PLA Basic Jade White, 1.75 мм, 1 кг, на котушці

Bambu Lab PLA Basic Jade White - якісний PLA-філамент для FDM/FFF 3D-друку, призначений для створення прототипів, декоративних виробів, функціональних деталей і навчальних моделей. Матеріал забезпечує стабільну екструзію, точне відтворення геометрії та гладку поверхню готових виробів.

Філамент виготовлений із біополімеру на основі полілактиду (PLA), який відзначається мінімальною усадкою, хорошою адгезією між шарами та простотою друку. Завдяки цьому він підходить як для початківців, так і для професійних користувачів.

Колір Jade White (Нефритово-білий) має м'який світлий відтінок, що чудово підходить для друку дизайнерських моделей, прототипів і виробів, які потребують акуратного зовнішнього вигляду.

Філамент має діаметр 1.75 ± 0.03 мм, поставляється на багаторазовій котушці (With Spool) та сумісний із більшістю FDM-принтерів, що підтримують нитку діаметром 1.75 мм.

Переваги

  • Висока стабільність друку.
  • Мінімальна усадка та деформація виробів.
  • Відмінна адгезія між шарами.
  • Гладка та рівномірна поверхня готових моделей.
  • Простий друк без складних налаштувань.
  • Підходить для швидкого друку.
  • Не має різкого запаху під час друку.
  • Біорозкладний матеріал на основі полілактиду (PLA).
  • Підходить для більшості FDM/FFF 3D-принтерів.
  • Поставляється на багаторазовій котушці.

Сфера застосування

Філамент Bambu Lab PLA Basic використовується для:

  • виготовлення прототипів;
  • друку інженерних моделей;
  • створення декоративних виробів;
  • виробництва сувенірної продукції;
  • друку макетів;
  • навчальних проєктів;
  • виготовлення корпусів електроніки;
  • друку деталей для хобі та DIY-проєктів.
