Даний комплект складається з сервомотора 60ST-M00630LB, серводрайвера AASD-15A і кабелів для підключення.Система є готовим рішенням для керування віссю верстата з ЧПУ.

Область застосування: обладнання для фрезерування, друкарське обладнання, пакувальне обладнання, харчова промисловість та виробництво напоїв, текстильна промисловість, пресове штампувальне обладнання, автомобільна промисловість та інше.

 

Серводвигун 60ST-M00630LB

Розшифрування маркування:

60ST - синусоїдальний постійний магніт із синхронним серводвигуном змінного струму. Розмір фланця 60 мм

М - тип енкодера (М означає фотоелектричний)

06 - номінальний момент обертання (~0.6 Нм)

3 - номінальна швидкість (~3000 об/хв)

 

60ST-M00630LB  - синхронний серводвигун змінного струму із встановленим на вал датчиком кута повороту, призначений для робіт, які вимагають високої точності, швидкості і низького рівня шуму. Двигун такого типу вимагає використання редуктора, оскільки має не жорстку фіксацію ротора ("плаваючий" ротор).

Для максимальної ефективності роботи сервомотора спільно з ним використовується серводрайвер моделі AASD-15A.

 

Переваги сервомотора:

  • Високий крутний момент
  • Стабільність крутного моменту
  • Точність позиціювання
  • Наявність датчика кута повороту
  • Повна відсутність вібрації
  • Швидкий розгін та гальмування
  • Висока потужність при невеликих розмірах

Серводрайвер AASD-15A

AASD-15A - сервопідсилювач, який призначений для управління серводвигуном 60ST-M00630LB. Ця модель серводрайвера підтримує максимально точне положення валу, яке задається контролером.Для управління напрямом і кроком обертання двигуна можна використовувати не тільки контролер, але і генератор імпульсів, який необхідно підключити в порт CN2 драйвера наступним чином:

Контакт 3: PP+ (STEP+) +5V

Контакт 14: PP- (STEP-) -5V

Контакт 4: PD+ (DIR+) +5V

Контакт 5: PD- (DIR-) -5V

Метод управління: синусоїдальне управління IGBT PWM

Режими управління:

  • Контроль за положенням
  • Контроль швидкості
  • Контроль положення/швидкості
