Повербанк 100000 mAh на 4 USB роз'єма

Powerbank O2 Project YT-2030 V1.1- портативний пристрій для заряджання з великою ємністю 100000 mAh. Підходить для заряджання різних пристроїв, таких як смартфони, планшети, навушники, смарт-годинник та інші гаджети.

O2 Project YT-2030 V1.1 має вбудований захист як самого повербанка, так і пристроїв, що заряджаються від перенапруги, перезарядки і перегріву, що підвищує безпеку використання. У повербанку використовуються літій полімерні акумулятори, які розраховані на 1000 циклів заряду-розряду.

Портативний зарядний пристрій оснащений 6 портами: вхід micro USB, вхід/вихід Type-C і 4 виходи USB. Максимальна потужність всіх виходів приблизно 37W. Для відображення рівня заряду та вихідної потужності є LED дисплей. На передній панелі також є 2 вбудовані LED ліхтарики, які включаються затисканням кнопки включення на 3 секунди.

Повербанк має високу ємність, що дозволяє провести безліч циклів зарядки пристроїв, що робить його відмінним вибором для тривалих поїздок або коли немає доступу до електричної розетки.

 

 Характеристики:

  • Виробник: O2 Project

  • Модель: YT-2030 V1.1

  • Ємність акумулятора: 100000 mAh

  • Номінальна ємність: 66000 mAh

  • Тип акумулятора: литий-полімерний (Li-Pol)

  • Входи:

    • micro USB: 5V 2A / 9V 2A

    • Type-C: 5V 3A / 9V 2.2A / 12V 1.5A

  • Виходи:

    • Type-C: 5V 3A / 9V 2.2A / 12V 1.5A

    • USB 1: 5V 2A

    • USB 2: 5V 2A

    • USB 3: 5V 3A / 9V 2A / 12V 1.5A

    • USB 4: 5V 3A / 9V 2A / 12V 1.5 A

  • Максимальна вихідна потужність: 37W

  • Функції захисту: захист від перенапруги, перезарядки, перегріву

  • Додаткові функції: ліхтарик, індикація рівня заряду

  • Габаритні розміри: 135*81*85 мм

  • Вага: 1300 г
