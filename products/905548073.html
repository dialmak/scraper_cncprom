Контролер MESA 5I24-16 на базі FPGA для шини PCI

MESA 5I24-16 - це універсальна програмована плата вводу/виводу на базі FPGA для шини PCI. 5I24-16 - це низькопрофільна PCI-карта (доступна з низькопрофільними та стандартними кронштейнами). EEPROMs з подвійною конфігурацією FPGA дозволяють легко відновлюватися після помилок програмування. Модулі вбудованого ПО призначені для апаратної генерації кроків, підрахунку квадратурних кодерів, генерації PWM, цифрового введення/виводу, віддаленого вводу/виводу Smart Serial, інтерфейсів BISS, SSI, SPI, UART та інших. Всі вбудовані програми управління рухом мають відкритий вихідний код і легко модифікуються для підтримки нових функцій або різних комбінацій функцій. Всі піни введення/виводу підтримують сигналізацію 3,3 В LVDS. Для всіх виводів передбачені резистори, так що вони можуть бути підключені безпосередньо до оптоізоляторів, контактів і т. д. 5I24-16 має 72 біта введення/виводу, доступних на трьох 50-контактних роз'ємів, всі роз'єми використовують розпиновку виводів, сумісних зі стійкою модуля вводу/виводу, і сумісні з усіма дочірніми платами Mesa 50 pin FPGA.

Можливості плати:

  • 3 порти по 50 пін для підключення дочірніх плат або виконавчих пристроїв
  • Всі піни введення / виводу підтримують сигналізацію 3,3 В LVDS
  • Для всіх висновків передбачені резистори
  • 72 біта вводу/виводу
