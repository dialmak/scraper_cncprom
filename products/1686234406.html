Кабель-подовжувач із роз'ємами USB 2.0 AM/AF завдовжки 0.5 м, USB-подовжувач "тато-мама", екранований кабель USB для передавання даних вилка-розетка

Високошвидкісний кабель-подовжувач USB 2.0 завдовжки 50 см на одному з кінців якого розміщений роз'єм USB AM ("тато", а на другому — роз'єм USB AF ("мама") з кріпильними "вухами" для виведення на корпус обладнання. До такої дати-кабелю можна під'єднувати контролери ЧПК, флеш накопичувачі, камери, принтери та іншу периферію.

Оскільки кабель є екранованим, він практично не піддається впливу електромагнітних випромінювань, тому забезпечує стабільне передавання даних зі швидкістю до 480 Мбіт/с.

 

Технічні характеристики: 

Інтерфейс: USB 2.0

Тип конектора 1: USB Type AM ("папа")

Тип конектора 2: USB Type AF ("мама")

Сумісність: USB 2.0; 3.0

Довжина разом із роз'ємами: 0.5 м

Максимальна швидкість передавання даних: 480 Мбіт/с

Маркування провідників: 28AWG/1P + 24AWG/2С

Матеріал провідників: луджена мідь

Матеріал ізоляції: ПВХ

Екранування: так

Відстань між монтажними отворами роз'єму USB Type AF: 30 мм

Різь монтажних отворів роз'єму USB Type AF: М3х0.5

Максимальна робоча температура: +75 °С

Колір: чорний

Вага нетто: 35 г

Стан: нове
