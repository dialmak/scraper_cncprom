Гайковий ключ типу C 45–52 мм для круглих шліцьових гайок, ключ під гайку ER32 тип UM 

Гайковий ключ типу C призначений для затягування та відкручування круглих гайок із бічними пазами. Робочий діапазон 45–52 мм дає змогу використовувати його з гайками відповідного діаметра за умови сумісності форми та розміру паза.

Робоча частина виготовлена з кованої вуглецевої сталі та має чорне захисне покриття. Гумова ручка забезпечує зручне утримання інструмента й зменшує ковзання під час роботи.

Ключ можна використовувати для обслуговування цангових патронів, верстатного оснащення, регулювальних кілець амортизаторів та інших механізмів із круглими шліцьовими гайками. Перед використанням необхідно перевірити відповідність діаметра гайки та геометрії паза робочій частині ключа.

Принцип роботи

Гак ключа встановлюють у бічний паз круглої гайки. Під час повороту ручки зусилля передається на паз, завдяки чому гайка затягується або відкручується. Гак має бути повністю встановлений у паз, щоб уникнути зісковзування та пошкодження гайки.

Особливості

  • С-подібна форма робочої частини для круглих гайок із бічними пазами.

  • Гумова ручка для зручного та надійного утримання.

  • Відкрита конструкція дає змогу працювати без повного охоплення гайки.

  • Підходить для обслуговування різних механічних і верстатних вузлів.

  • Для роботи не рекомендується використовувати молоток або подовжувати ручку трубою.

Сфери застосування

  • Цангові патрони та верстатне оснащення.

  • Верстати й обладнання з ЧПК.

  • Круглі гайки механічних вузлів.

  • Регулювальні кільця амортизаторів.

  • Ремонт і технічне обслуговування обладнання.
