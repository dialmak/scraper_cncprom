Шарнірна опора для профілю

Шарнірна регульована опора SRO-М16x80-D100H з металевим різьбовим стрижнем М16, круглою нейлоновою основою 100 мм і каучуковою підкладкою для гасіння коливань використовується загалом для регулювання висоти профілю, але може застосовуватися і для інших конструкцій. Для встановлення опори на профіль необхідно придбати плиту для шарнірних опор із різзю М16. Розмір цієї плити підбирається з огляду на серію профілю. Ця опора має отвори для кріплення до підлоги. Статичне навантаження 2000 кг. 

Комплект постачання 

- Шарнірна регульована опора для профілю, SRO-М16x80-D100H (1 шт.)

- Гайка, різь М16 (1 шт.)
