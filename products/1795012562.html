Модуль для керування зарядом батареї XY-L30A, контролер заряду акумулятора з дисплеєм, плата для автоматичного увімкнення/вимкнення заряду акумулятора (6-60 V)

 

Контролер XY-L30A використовується для автоматичного увімкнення та вимкнення зарядного пристрою заданими параметрами, які встановлюються за допомогою трьох кнопок (SET, UP і DOWN), встановлених на платі модуля. Контролер оснащений дисплеєм з підсвіткою, на якому відображається поточна напруга, рівень та час заряджання.

Для заряджання акумулятора потрібне зарядний пристрій з достатньою вихідною напругою. Реле замикається, коли напруга акумулятора дорівнює або падає нижче заданого параметра, і розмикається, коли досягається верхня межа.

 

Основні функції контролера:

1. Контроль заряду акумулятора, автоматичне вимкнення відповідно заданим параметрам;

2. Регульований час зарядки;

3. Підтримка функції приймання даних та установки параметрів через UART (рівень TTL);

 

Характеристики:

  • Вхідна напруга: від 6 V до 60 V;
  • Вбудоване реле: SLA-05VDC-SL-A;
  • Точність відображення: 0.1 V;
  • Точність управління: 0.1 V
  • Діапазон напруги: 0-60 V постійного току;
  • Струм зарядки: до 30 А;
  • Колір дисплея: синій;
  • Розмір плати: 92x45 мм;
  • Відображення інформації: напруга, час, відсоток заряду
  • Формат часу: 00:00 (макс 99.99 (~100 годин))
  • Сумісність: універсальний

 

Процедура установки параметрів:

1.  Натисніть та утримуйте кнопку SET (<3 сек) для входу в екран налаштування параметрів;

2. За допомогою кнопок UP/DOWN установіть потрібне значення (для швидкої зміни затисніть кнопку);

3. Для переходу до наступного параметра, зробіть короткочасне натискання кнопки SET;

3. Після встановлення всіх параметрів, затисніть кнопку SET (<3 сек), щоб вийти з режиму налаштування;

 

Установка параметрів акумулятора:

Перед зарядкою акумулятора установіть мінімальну напругу (вольт-LI) та максимальну напругу (вольт-HI). Ці значення потрібні для розрахунку та відображення рівня заряду батареї.

Максимальна напруга також використовується для визначення моменту припинення заряджання.

 

Установка часу зарядки:

Крім контролю верхньої межі напруги в процесі заряджання, є другий спосіб зупинити зарядку: після заданого часу. Ця функція за замовчуванням відключена і визначається як параметр часу --:-- h. У цьому стані заряджання продовжується нескінченно, поки напруга батареї не досягне максимально заданого рівня.

Для активації функції заряджання з обмеженням часу, необхідно встановити ненульовий час в діапазоні від мінімум 1 хвилини (00:01h) до максимум 100 годин (99:59h).
