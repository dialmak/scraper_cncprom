Контролер 7I85S 4-канальний енкодер, 8 диференціальних виходів, одноканаловий інтерфейс RS-422

7I85S - це чотириканальний енкодер c 8 диференціальними виходами та одноканаловий інтерфейс RS-422 для серії інтерфейсних плат вводу / виводу Mesa Anything I / O. 7I85S розроблений для додатків управління рухом. 7I85S має чотири входи TTL або диференціального енкодера, включаючи індексні, вісім диференціальних виходів, які можна використовувати в якості чотирьох пар диференціальних вихідних сигналів step+ dir або ШІМ-виходів або інших вихідних функцій. Один послідовний інтерфейс RS-422 призначений для розширення вводу / виводу. З'єднання контролера - це роз'єм DB25, який відповідає розташуванню 25-контактних плат вводу-виводу Mesa. Всі буферизовані входи / виходи закінчуються вставними гвинтовими клемами 3,5 мм (входять в комплект постачання).
