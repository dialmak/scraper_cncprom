Інтелектуальний зарядний пристрій для свинцево-кислотних акумуляторів
RJ Tianye 12V 6A -
![](https://images.prom.ua/5059146328_w640_h2048_main2.jpg?fresh=1&PIMAGE_ID=5059146328)
зарядний пристрій, призначений для заряджання автомобільних та мотоциклетних акумуляторів. Підходити для зарядки свинцево-кислотних акумуляторів ємністю 4-100 Ампер*ч. Має різні режими заряджання, які перемикаються за допомогою кнопки "MODE" та LCD дисплей для відображення різних даних. Кожне наступне натискання кнопки "MODE" змінює режим заряджання.
Режими заряджання:
Автомобільний акумулятор - заряджання в даному режимі підходить для свинцево-кислотних акумуляторів з напругою 12V, які використовуються в автомобілях, сільськогосподарській техніці, вантажівках.
Старт/стоп акумулятор - використовується для заряджання автомобільних акумуляторів з функцією запуску та зупинки.
Мотоциклетний акумулятор – для всіх видів мотоциклетних свинцево-кислотних акумуляторів з напругою 12V.
Імпульсний режим заряду (pulse repair) - використовується для десульфатації пластин, для цього зарядний пристрій періодично подає напругу і після повної зарядки акумулятор розряджається. У процесі пластини очищаються від сульфату свинцю, що відновлює акумуляторну батарею та продовжує термін служби.
Функція "Зима/Літо" позволяє автоматично визначити температуру навколишнього середовища, тому ручне налаштування не потрібне.
Зарядний пристрій має різні типи захисту, тому його можна підключити до акумулятора для заряджання на невизначений термін.
