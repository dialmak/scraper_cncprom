Контролер крокового двигуна (генератор імпульсів) PG-2ET06 V2.1
![](https://images.prom.ua/4568630601_w640_h2048_descr.jpg?fresh=1&PIMAGE_ID=4568630601)
Контролер PG-2ET06 - являє собою малогабаритний автономний контролер, призначений для управління обертанням (траєкторією, швидкістю, плавністю зупинки) крокових двигунів в системах автоматизації. Перемикачі DIP1/DIP2 використовуються для вибору швидкості обертання та різкого запуску/зупинки (без регулювання швидкості) крокового двигуна, DIP3 - для зміни напрямку обертання, DIP4 - інверсія виходу EN.
AD3 - використовується для регулювання швидкості обертання двигуна, AD4 - для регулювання прискорення.
Частота імпульсів на виході становить від 160 Гц до 40 кГц. Живлення даного генератора імпульсів здійснюється імпульсним джерелом живлення DC 12V або 24 V.
Для контролю наявності живлення та ходом роботи контролера можна використовувати світлодіодні індикатори.
Модель відрізняється своєю простотою у використанні, стабільною роботою та невисокою вартістю.
До основних особливостей та функцій контролера відносяться:
Не вимагає підключення до комп'ютера
Висока точність
4 режими управління траєкторією руху двигуна
2 режими зупинки: різка та плавна
Можливість регулювання прискорення/уповільнення обертання
Підтримка вбудованого та зовнішнього потенціометрів для регулювання швидкості
Розміщення потенціометрів та DIP-перемикачів зовні (для зручності регулювання)
Поради!
Зовнішній потенціометр необхідно підключати до PG-2ET06 перед включенням живлення. В іншому випадку потенціометр може бути не впізнаний
Після регулювання DIP-перемикачів необхідно перезапустити контролер для його коректної роботи
Зверніть увагу! Цей контролер призначений для використання тільки в поєднанні з драйвером, його не можна використовувати для безпосереднього керування двигуном.
