32-024 Кутовий з'єднувач CCL4590 для станкового алюмінієвого профілю серії 45, зовнішній куточок для профілю
https://cncprom.ua/ua/p1713054960-uglovoj-soedinitel-ccl4590.html

Кутовий з'єднувач CCL4590 для станкового алюмінієвого профілю серії 45, зовнішній куточок для з'єднання конструкційного профілю під кутом 90 градусів
CCL4590 - кріпильний елемент з алюмінієвого сплаву, який застосовується для зовнішнього з'єднання відрізків[конструкційного профілю серії 45](https://cnc.prom.ua/g2432613-alyuminievyj-profil) під кутом 90 градусів. Попри те, що куточок монтується досить швидко й без застосування складних інструментів, він здатний забезпечити надійність і жорсткість конструкції.
Ширина паза відповідного профілю має становити не менш ніж 8 мм.
Корисна порада!
Уважно ознайомтеся з кресленнями виробу, оскільки є профілі серії 45 с якими з'єднувач цієї моделі не сумісний
Куточок може використовуватися для з'єднання профілів інших серій (див. креслення виробу)
