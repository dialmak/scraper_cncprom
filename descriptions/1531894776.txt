10-903 Захисні окуляри від лазерного випромінювання 635-760 нм SK-165, окуляри для захисту очей від червоного лазера
https://cncprom.ua/ua/p1531894776-zaschitnye-ochki-lazernogo.html

Захисні окуляри від лазерного випромінювання 635-760 нм SK-165, робочі окуляри для захисту очей від червоного лазера, захисні протилазерні окуляри
SK-165 - промислові відкриті окуляри, які призначені для захисту очей під час роботи з червоним напівпровідником лазером із довжиною хвилі в діапазоні 635-760 нм. Ця модель обладнана бічними екранами, що слугують для збільшення поля зору під час роботи, а також для захисту зору від периферичного впливу лазера.
Принцип оптичного відсіювання променів забезпечує блокування небезпечних для зору хвиль лазерного випромінювання, не перекриваючи водночас інших кольорів. Така особливість дає змогу досить комфортно здійснювати налагодження обладнання без потреби зняття аксесуара.
Лінзи виготовлені з полікарбонатного скла, тому окуляри не втрачають своїх захисних властивостей навіть у разі появи на поверхні подряпин і потертостей. Дужки окулярів мають регулювання за довжиною, а також отвори для страхувальної тасьми.
Постачаються окуляри SK-165 у міцному чохлі на блискавці. До комплекту постачання також входить тканина для очищення поверхні скла.
Застосування: лазерні покажчики, прилади для сценічного світла, косметологічні інструменти тощо.
Увага! Окуляри від лазерного випромінювання не є стовідсотковим захистом очей, а лише додатковою перешкодою для короткочасного впливу лазерного пучка на сітківку та кришталик ока
