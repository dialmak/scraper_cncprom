Комплект для фотополімерного 3D-друку Creality: UV-смола Fast Resin Grey 1000 г + набір інструментів UV Resin Tool Kit
До комплекту входить швидкотвердіюча фотополімерна смола Creality Fast Resin UV Curable Resin сірого кольору об'ємом 1000 г та оригінальний набір аксесуарів Creality Ender UV Resin Tool Kit, призначений для зручної роботи зі смолою, її фільтрації, очищення інструментів і підтримання чистоти робочого місця.
Фотополімерна смола Creality Fast Resin забезпечує швидку полімеризацію під ультрафіолетовим випромінюванням із довжиною хвилі 405 нм, має хорошу плинність, низьку усадку та дозволяє отримувати моделі з високою деталізацією, чіткими контурами й гладкою поверхнею. Смола сумісна з більшістю LCD, MSLA та DLP фотополімерних 3D-принтерів, що працюють із джерелом світла 405 нм.
Комплект аксесуарів Creality Ender UV Resin Tool Kit робить роботу з фотополімерною смолою більш чистою, безпечною та зручною. Усі інструменти підібрані для виконання основних операцій під час друку та післяобробки: переливання й фільтрації смоли, захисту робочого місця, очищення обладнання та догляду за інструментами. Це дозволяє підтримувати порядок на робочому столі, зменшити втрати смоли та підвищити комфорт під час експлуатації фотополімерного 3D-принтера.
Такий комплект стане чудовим вибором як для користувачів, які лише починають працювати з фотополімерним друком, так і для досвідчених майстрів, що прагнуть мати під рукою все необхідне для друку та післяобробки моделей.
