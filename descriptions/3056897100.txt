03-159 Кабель-подовжувач із роз'ємами USB 2.0 тип "В"- 0.5 м, USB-подовжувач "папа-мама", кабель USB для передачі даних

Кабель-подовжувач із роз'ємами USB 2.0 тип "В" (ВM/ВF) завдовжки 0.5 м, USB-подовжувач "папа-мама", екранований кабель USB для передавання даних вилка-розетка
Високошвидкісний кабель-подовжувач USB 2.0 тип "В" завдовжки 50 см на одному з кінців якого розміщений роз'єм USB ВM ("папа", а на другому — роз'єм USB ВF ("мама") з кріпильними "вухами" для виведення на корпус обладнання. До такого кабелю можна під'єднувати контролери ЧПК, флеш-накопичувачі, камери, принтери та іншу периферію.
Оскільки кабель є екранованим, він практично не піддається впливу електромагнітних випромінювань, тому забезпечує стабільне передавання даних зі швидкістю до 480 Мбіт/с з інтерфейсом USB Type B.
Технічні характеристики:
Інтерфейс: USB 2.0 Type B
Тип конектора 1: USB Type ВM ("папа")
Тип конектора 2: USB Type ВF ("мама")
Довжина разом із роз'ємами: 0.5 м
Максимальна швидкість передавання даних: 480 Мбіт/с
Маркування провідників: 28AWG/1P + 24AWG/2С
Матеріал провідників: луджена мідь
Матеріал ізоляції: ПВХ
Екранування: так
Відстань між монтажними отворами роз'єму USB Type ВF: 30 мм
Різь монтажних отворів роз'єму USB Type AF: М3х0.5
Максимальна робоча температура: +80 °С
Колір: чорний
Вага нетто: 28 г
Стан: нове
