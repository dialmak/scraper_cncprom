03-098 Модуль керування заряджанням батареї XY-CD63L
https://cncprom.ua/ua/p1942451180-modul-upravleniya-zaryadkoj.html

XY-CD63L - являє собою модуль керування заряджанням батареї. Він є контролером напруги, який вмикає та вимикає вихід за допомогою реле, яке діє лише як перемикач і не може змінювати напругу.
Модуль підтримує два режими роботи: контроль заряду та контроль розряду.
Контроль заряду: цей режим використовується для контролю заряду, щоб запобігти перезаряджанню.
Контроль розряду: цей режим використовується для контролю розряду акумулятора, щоб запобігти надмірному розряду і продовжити термін служби акумулятора.
Призначення кнопок:
Кнопка UP - коротке натискання для перемикання між відображенням % і часу; тривале натискання протягом 5с для перемикання режимів; режим заряду; вхід; режим розряду; вихід.
Кнопка SET - коротке натискання для відображення поточного встановленого параметра, тривале натискання кнопки SET для встановлення параметра.
Кнопка DOWN - коротке натискання вимикає/вмикає реле (функція аварійної зупинки).
Відображення:
UP: верхня межа напруги;
DN : нижня межа напруги;
OP: час проведення;
DOP: час затримки провідності (0-999 секунд);
FOP у режимі розряду: час примусового запуску (0-10 секунд)
