10-902 Захисні окуляри від лазерного випромінювання 560-620 нм SK-202, окуляри для захисту очей від жовтого та червоного лазера
https://cncprom.ua/ua/p1535919019-zaschitnye-ochki-lazernogo.html

Захисні окуляри від лазерного випромінювання 560-620 нм SK-202, робочі окуляри для захисту очей від жовтого, жовтогарячого та червоного лазерів, захисні проти лазерні окуляри
SK-202 - промислові відкриті окуляри, які призначені для захисту очей під час роботи з жовтим, жовтогарячим та червоним лазером із довжиною хвилі в діапазоні 560-620 нм. Ця модель обладнана бічними екранами, що слугують для збільшення поля зору під час роботи, а також для захисту зору від периферичного впливу лазера.
Принцип оптичного відсіювання променів забезпечує блокування небезпечних для зору хвиль лазерного випромінювання, не перекриваючи водночас інших кольорів. Така особливість дає змогу досить комфортно здійснювати налагодження обладнання без потреби зняття аксесуара.
Лінзи виготовлені з полікарбонатного скла, тому окуляри не втрачають своїх захисних властивостей навіть у разі появи на поверхні подряпин і потертостей. Дужки окулярів не мають регулювання за довжиною, але обладнані прогумованими накладками та отворами для страхувальної тасьми.
Постачаються окуляри SK-202 у міцному чохлі на блискавці. До комплекту постачання також входить тканина для очищення поверхні скла.
Застосування: лазерні покажчики, прилади для сценічного світла, косметологічні інструменти тощо.
Увага! Окуляри від лазерного випромінювання не є стовідсотковим захистом очей, а лише додатковою перешкодою для короткочасного впливу лазерного пучка на сітківку та кришталик ока
