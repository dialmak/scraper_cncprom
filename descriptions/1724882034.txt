15-008 Кріплення для циліндричного шпинделя діаметром 105 мм, алюмінієвий кронштейн-тримач для шпинделя ЧПК
https://cncprom.ua/ua/p1724882034-kreplenie-dlya-tsilindricheskogo.html

Кріплення для циліндричного шпинделя діаметром 105 мм, алюмінієвий кронштейн-тримач для шпинделя ЧПК, пристосування для фіксації шпинделя
Цей кронштейн застосовується для жорсткого та надійного кріплення циліндричного шпинделя діаметром 105 мм на модулі лінійного переміщення верстата з ЧПК.
Електродвигун поміщається в посадкове місце та притискається за допомогою гвинтів (два крайніх слугують для затискання кронштейна, а середній для розтискання).
На фланці тримача кріпильних отворів немає. Таке рішення робить кронштейн універсальнішим, позаяк їх місце розташування можна спроєктувати залежно від компонування осі Z.
Як матеріал використовується алюміній. Метод виготовлення — лиття.
Корисна порада!
Будь ласка, уважно ознайомтеся з кресленням виробу перед купівлею
Основні технічні характеристики:
Діаметр відповідного шпинделя: 105 мм
Матеріал: алюміній
Метод виготовлення: лиття
Обробка поверхні: немає
Монтажні отвори на фланці: немає
Вага нетто: 2.2 кг
Стан: нове
