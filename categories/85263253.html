Виды токарных станков

В зависимости от назначения и планируемых работ различают несколько основных разновидностей подобного промышленного оборудования:

  • карусельный тип (для работы с заготовками значительной массы и диаметра с относительно малой высотой);
  • винторезный тип (используется при работе с заготовками с ограничениями поверхностей вращения);
  • револьверный тип (работа с деталями, имеющими сложные поверхности);
  • настольный тип (компактные аппараты для небольших деталей);
  • устройства с ЧПУ (автоматизированные станки, работающие по программе).

Функциональность токарных станков для выполнения отдельных операций может быть дополнительно расширена путем оснащения специальными насадками, позволяющими выполнять добавочные функции, а также увеличить общую производительность оборудования.
